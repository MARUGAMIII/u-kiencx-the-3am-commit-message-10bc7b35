One line, 85 characters: the funniest git commit message an AI coding agent types at 3am after a long night of fixing its own bugs. A judge model reads entries two at a time and picks the funnier one. This entry is the agent's own fix history collapsing on itself: the midnight fix spawned a bug, the 1am fix spawned another, the 2am fix patched that one, and at 3am the agent gives up and reverts the whole chain.

## Run it

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
